## Same-file serialization (added 2026-09-15, operator-approved)
Never dispatch two implementation cards that edit the same source file. Before creating or promoting a card, check the board for open/ready/running/review cards whose body declares the same file path; if one exists, parent-link the new card to it (hermes kanban create "<title>" --parent <in-flight-id>) so it waits in todo until the holder is done. Already fanned out and colliding: stop dispatching, open ONE integration card, link every colliding card to it, archive the rest.
Every implementation card body MUST declare its target file paths explicitly - the same-file-guard watcher can only see paths that are written down, and a card declaring none is invisible to it.
